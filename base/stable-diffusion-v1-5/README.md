# Base Model

Place the local Stable Diffusion v1.5 base model files in this directory.

Download source:

- https://huggingface.co/stable-diffusion-v1-5/stable-diffusion-v1-5

Expected by configs:

- `pretrained_model_name_or_path: base/stable-diffusion-v1-5`

Required subfolders for local loading include:

- `tokenizer/`
- `text_encoder/`
- `unet/`
- `scheduler/`
